原価計算

原価計算は、CVP分析・原価計算方式の選択・標準原価の差異分析・意思決定・設備投資と、「意思決定に役立つ原価情報」を扱う管理会計中心の科目です。計算の型が決まっているため反復で確実に得点でき、配点25点の安定した得点源になります。各手法の前提（埋没原価は無視、貢献利益で判断など）を理解すれば応用が効きます。

配点25点・後半（工業簿記・原価計算で90分）。管理会計寄り。意思決定会計・CVP・戦略的原価計算を問う。1科目でも40%（10点）未満だと足切りで不合格になるため、この科目でも最低ラインの確保が必須。

CVP分析の基本指標

貢献利益（限界利益）を軸に、損益分岐点と安全性を測る。

指標計算式意味・ポイント
貢献利益(限界利益)売上高 − 変動費固定費回収と利益の源泉
貢献利益率貢献利益 ÷ 売上高売上1円あたりの貢献額
損益分岐点売上高固定費 ÷ 貢献利益率利益ゼロとなる売上高
損益分岐点販売量固定費 ÷ 単位あたり貢献利益利益ゼロとなる数量
安全余裕率(実際売上高 − 損益分岐点売上高) ÷ 実際売上高何%売上が落ちても赤字化しないか
経営レバレッジ係数貢献利益 ÷ 営業利益安全余裕率の逆数。売上変動の利益増幅度
目標利益売上高(固定費 + 目標利益) ÷ 貢献利益率目標営業利益を得る売上高
経営レバレッジ係数 × 安全余裕率 = 1 が常に成立する。

全部原価計算 と 直接原価計算

固定製造間接費を製品原価に含めるか（全部）、期間費用とするか（直接）で営業利益が食い違う。

項目全部原価計算直接原価計算
固定製造間接費の扱い製品原価に算入（在庫にも配分）発生した期の期間費用
利益への影響生産量が増えると利益が増えやすい生産量に左右されず販売量で決まる
外部報告(制度会計)認められる認められない（内部管理用）
利益差の原因在庫に含まれる固定費の増減在庫に固定費を含めない
固定費調整調整不要（そのまま制度上の利益）全部原価計算利益＝直接利益＋(期末在庫の固定費−期首在庫の固定費)
在庫が増加（生産>販売）すると全部原価計算利益 > 直接原価計算利益。減少すると逆転する。

標準原価差異分析（三分法・四分法）

実際発生額と標準配賦額の差を原因別に分解する。製造間接費（公式法変動予算）の分解が要。

差異計算式備考
材料 価格差異(標準単価 − 実際単価) × 実際消費量購入・市況要因
材料 数量差異(標準消費量 − 実際消費量) × 標準単価使い方・歩留要因
労務 賃率差異(標準賃率 − 実際賃率) × 実際作業時間賃率要因
労務 時間(作業能率)差異(標準作業時間 − 実際作業時間) × 標準賃率作業効率要因
予算差異実際発生額 − 実際操業度における予算許容額浪費・節約
能率差異標準配賦率 × (実際操業度 − 標準操業度)三分法。四分法では変動費分と固定費分に分割
操業度差異固定費率 × (基準操業度 − 実際操業度)設備の遊休・過剰稼働
四分法は三分法の能率差異を「変動費能率差異＝変動費率×(実際−標準操業度)」と「固定費能率差異＝固定費率×(実際−標準操業度)」に分ける。各差異の合計は必ず総差異に一致する。

業務的意思決定の判断基準

差額原価・差額収益（＝関連原価のみ）で比較し、埋没原価は無視する。

意思決定判断の軸無視するもの
特別注文の受注可否差額収益 > 差額原価（増分貢献利益>0）なら受注既存で発生済の固定費(埋没)
追加加工の可否追加加工後の増分収益 > 追加加工費なら加工分離点までの結合原価(埋没)
内製か外注か内製の回避可能原価 と 外注購入原価を比較回避できない固定費
セグメントの継続/廃止そのセグメントの貢献利益(個別固定費控除後)が正なら継続配賦された共通固定費
『関連原価＝将来発生し、かつ代替案間で差が出る原価』のみを比較する。過去原価は常に埋没原価。

設備投資の経済性計算

貨幣の時間価値を考慮する割引法と、考慮しない非割引法に大別。

方法内容・判定基準特徴
正味現在価値法(NPV)将来CFの現在価値合計 − 投資額。NPV>0なら採用割引法。金額で評価、加法性あり
内部利益率法(IRR)NPV=0となる割引率。IRR>資本コストなら採用割引法。率で評価、複数解の恐れ
収益性指数(PI)将来CFの現在価値 ÷ 投資額。1超なら採用割引法。資金制約下の優先順位付け
回収期間法投資額 ÷ 年々のCF(等額時)。短いほど有利非割引が原則。安全性・流動性重視
会計的利益率法(ARR)平均利益 ÷ 投資額。高いほど有利非割引。CFでなく利益ベース
IRRは資本コストと比較して採否を決める。NPVとIRRは単独案では通常同じ結論だが、排他的案の優劣では食い違うことがあり、その場合はNPVを優先する。

活動基準原価計算(ABC)と伝統的配賦

製造間接費を活動（コストプール）ごとに、原因となるコストドライバーで配賦する。

項目伝統的原価計算ABC
配賦基準操業度(直接作業時間・機械時間など)単一基準が中心活動ごとのコストドライバー(段取回数・検査時間など)
少量多品種製品の原価過小評価されやすい実態に近い(段取等を正しく負担)
適する状況間接費が小さい・製品が同質間接費が大きい・多品種
計算コスト低い高い(活動の把握が必要)
ABCの手順: (1)活動ごとにコストプール集計 → (2)コストドライバー確定 → (3)ドライバー1単位あたりレート算定 → (4)製品の消費量で配賦。

予算管理の体系

総合予算は損益・資金・財政状態の計画を統合したもの。

区分内容例
損益予算収益・費用の計画販売予算・製造予算・販管費予算
財務予算資金と財政状態の計画現金予算・見積貸借対照表
固定予算特定の操業度前提で編成予算差異分析が操業度変化に弱い
変動予算操業度に応じて許容額が変動実績と同じ操業度で比較でき差異分析に有用
予算差異分析では、実際操業度に対応する予算許容額(変動予算)と実績を比較するのが原則。

設備投資のNPV — 税引後キャッシュフローと減価償却タックスシールド

設備投資の意思決定で割引前の利益をそのまま並べてはいけない理由は二つあります。第一に、法人税は「利益」ではなく「キャッシュ」を確実に流出させるため、評価はすべて税引後キャッシュフロー(CF)で行う必要があること。第二に、貨幣の時間価値により将来のCFは現在価値に割り引かねばならないことです。NPV法はこの二つを同時に満たし、NPV(将来CFの現在価値合計−投資額)が正なら採用、と一義的に判定できます。

営業CFの組み立て方が最重要ポイントです。減価償却費は現金支出を伴わない費用ですが、課税所得を圧縮して納税額を減らすため、その節税額だけ間接的にCFを生みます。これを減価償却の節税効果(タックスシールド)と呼びます。年々の税引後営業CFは「税引前純現金流入×(1−税率)＋減価償却費×税率」で求めるのが定石です。前半は現金収支ベースの利益に対する税引後の手取り、後半が減価償却がもたらす節税額であり、両者を分けて捉えると計算ミスが激減します。

割引は、毎年のCFが等額(年金型)なら年金現価係数を、金額が年ごとに異なるなら各年の現価係数を掛けて合計します。投資額(初期支出)は原則0年度に一括流出として割り引かず、そのまま差し引きます。設例では税率30%、割引率8%(5年の年金現価係数3.993)を用います。

検算の勘所は、①減価償却は費用としてCFの外側で税率を掛けるだけで、CFにそのまま加算しない(利益計算の中では費用計上、CF換算では非現金なので戻す、という二段構えを混同しない)、②残存価額・売却損益の税効果、運転資本の回収などがあれば別途最終年度に加える、の2点です。

設例

投資額12,000,000円、耐用年数5年、残存価額0の設備を定額法で償却。この設備は毎年、税引前の純現金流入(現金収益−現金費用)を4,000,000円もたらす。法人税率30%、資本コスト(割引率)8%、5年の年金現価係数3.993。NPVを求め採否を判定する。

  1. 年間減価償却費 = 12,000,000 ÷ 5 = 2,400,000円
  2. 税引後営業CF = 税引前純現金流入×(1−税率) + 減価償却費×税率 = 4,000,000×0.70 + 2,400,000×0.30 = 2,800,000 + 720,000 = 3,520,000円
  3. CFの現在価値合計 = 3,520,000 × 3.993 = 14,055,360円
  4. NPV = 14,055,360 − 12,000,000 = 2,055,360円 > 0 → 投資を採用
  5. 検算: 税引後CF3,520,000を利益ベースに戻すと、税引前利益=純現金流入4,000,000−減価償却2,400,000=1,600,000、税引後利益=1,600,000×0.7=1,120,000、これに非現金の減価償却2,400,000を足し戻すと3,520,000となり一致する。
答え： NPV ≈ +2,055,360円で正。よって当該設備投資は採用すべきである。

IRR・回収期間の実務 — 補間法・割引回収期間・NPV法との優劣

内部利益率(IRR)は「NPV=0となる割引率」であり、投資が生み出す利回りそのものを表します。IRRが資本コストを上回れば採用します。毎年のCFが等額なら、NPV=0の条件は『投資額 = 年CF×年金現価係数』、すなわち『必要な年金現価係数 = 投資額 ÷ 年CF』に帰着します。この係数に一致する割引率を係数表から挟み込み、線形補間で近似するのが試験・実務の標準手順です。

補間の式は、低い率r1(係数F1)と高い率r2(係数F2)、目標係数Fに対し、IRR ≒ r1 + (F1−F)÷(F1−F2)×(r2−r1)です。F1>F>F2の順(割引率が上がると係数は下がる)を必ず確認します。IRRは率で直感的な一方、規模の異なる案件の優劣付けには不向き(NPV法の加法性が勝る)、CF符号が複数回変わると複数解が生じうる、という限界があります。

回収期間法は『投資額を何年で取り戻すか』を見る安全性・流動性重視の指標です。年CFが等額なら回収期間=投資額÷年CF。短いほど有利ですが、回収後のCFと時間価値を無視する点が弱点です。これを補うのが割引回収期間法で、割引後CFの累計が投資額に達する年数を測ります。時間価値を考慮するぶん通常の回収期間より長く出ます。試験では回収期間は非割引が原則である点に注意してください。

設例

投資額8,000,000円、毎年の税引後CFが2,500,000円で4年間続く案件。年金現価係数は9%で3.2397、10%で3.1699。資本コストは8%。IRRと(非割引)回収期間を求め、採否を判定する。

  1. NPV=0の必要係数 = 投資額 ÷ 年CF = 8,000,000 ÷ 2,500,000 = 3.2000
  2. 3.2000は9%の3.2397と10%の3.1699の間にある → 9%と10%で補間
  3. IRR ≒ 9% + (3.2397−3.2000)÷(3.2397−3.1699)×(10%−9%) = 9% + 0.0397÷0.0698×1% ≒ 9% + 0.57% = 約9.57%
  4. IRR 9.57% > 資本コスト8% → 採用
  5. 回収期間 = 8,000,000 ÷ 2,500,000 = 3.2年(4年で総CF10,000,000>投資額なので回収可能、検算OK)
答え： IRR ≈ 9.57%(>8%)で採用可。回収期間は3.2年。

差額原価収益分析 — 特別注文・内外製・追加加工の共通ロジック

業務的意思決定はすべて『その案を採ることで増減する収益と原価(差額)だけを比べ、増分利益が正なら採る』という一本のロジックで貫かれます。すでに発生し、どの案でも変わらない原価は埋没原価(サンクコスト)として一切無視するのが鉄則です。過去支出や配賦済みの共通固定費に引きずられないことが得点の分かれ目になります。

特別注文は、遊休能力があれば既存の固定費は埋没するので、注文価格が単位変動費を上回るかぎり(増分貢献利益が正)受注が有利です。ただし特別注文専用の追加設備費や、既存市場の値崩れといった機会損失があれば、それらは差額原価として必ず算入します。

内外製(自製か購入か)は、自製をやめれば回避できる原価(回避可能原価=変動費＋一部の個別固定費)と外注購入価格を比べます。配賦されているだけで自製をやめても消えない固定費は比較に入れません。追加加工(連産品)は、分離点までの結合原価は埋没であり、分離点で売る場合と追加加工して売る場合の『増分収益−追加加工費』が正なら加工する、と判断します。いずれも土俵は同じで、変わる金額だけを見る、という一点に尽きます。

設例

(1)特別注文: 通常売価1,000円・単位変動費600円・遊休能力あり。得意先から3,000個を@700円で引き合い。(2)内外製: 部品の自製原価は直接材料200・直接労務150・変動間接費100・配賦固定費120(うち自製中止で消えるのは40)。外注は@500円。(3)追加加工: 連産品を分離点で@800円で売れるが、追加加工費250円/個をかけると@1,100円で売れる。それぞれ判定する。

  1. (1) 増分収益 = 3,000×700 = 2,100,000、増分原価 = 3,000×600 = 1,800,000、増分利益 = 300,000円 > 0 → 受注する(固定費は遊休のため埋没で無視)
  2. (2) 自製の関連原価 = 200+150+100+回避可能固定費40 = 490円。外注500円 > 自製490円 → 自製が10円/個有利。配賦固定費のうち消えない80円は無視する
  3. (3) 追加加工の増分収益 = 1,100−800 = 300円、追加加工費 = 250円、増分利益 = 50円/個 > 0 → 追加加工して販売する(分離点までの結合原価は埋没)
  4. 検算: いずれも『変わる金額のみ』で構成され、埋没原価(既存固定費・配賦固定費・結合原価)を除外している点を確認
答え： (1)受注する(+300,000円)、(2)自製する(10円/個有利)、(3)追加加工する(+50円/個)。

多品種CVPと感度分析 — セールスミックス・経営レバレッジ

複数製品を扱う企業のCVP分析では、製品ごとに貢献利益率が異なるため、販売数量の構成比(セールスミックス)が一定という前提を置いて計算します。実務的にはミックスの比率で1つの『製品バスケット(セット)』を定義し、そのセット1組あたりの貢献利益で固定費を割って損益分岐点セット数を求め、各製品数量に展開します。ミックスが変われば損益分岐点も動くため、前提の明示が不可欠です。

感度分析(sensitivity analysis)は、売価・変動費・数量・固定費といった前提が変動したとき営業利益がどれだけ振れるかを測るものです。とりわけ経営レバレッジ係数(DOL=貢献利益÷営業利益)は、売上が1%変化したとき営業利益が何%変化するかを示す増幅率で、固定費比率が高いほど大きくなります。DOLが分かれば『売上◯%増で利益△%増』が即座に読め、感度分析の中核になります。安全余裕率の逆数がDOLである点も押さえておくと検算に使えます。

設例

製品A(売価400・変動費240、貢献利益160)と製品B(売価1,000・変動費700、貢献利益300)を、販売数量比3:1で売る。共通固定費1,560,000円。損益分岐点の各製品数量を求め、さらにA単独12,000個・B規模も同構成で営業利益360,000円のときの経営レバレッジ係数と『数量10%増』の利益への影響を示す。

  1. 1セット(A3個+B1個)あたり貢献利益 = 3×160 + 1×300 = 480+300 = 780円
  2. 損益分岐点セット数 = 固定費 ÷ セット貢献利益 = 1,560,000 ÷ 780 = 2,000セット
  3. 損益分岐点数量: A = 2,000×3 = 6,000個、B = 2,000×1 = 2,000個。検算: 貢献利益 = 6,000×160+2,000×300 = 960,000+600,000 = 1,560,000 = 固定費 → 利益0で一致
  4. 感度分析の例(営業利益360,000円・貢献利益1,920,000円の局面): 経営レバレッジ係数 DOL = 貢献利益 ÷ 営業利益 = 1,920,000 ÷ 360,000 ≒ 5.33
  5. 数量10%増 → 営業利益は約10%×5.33 = 約53.3%増。検算: 貢献利益が10%増で2,112,000、固定費1,560,000を引くと552,000。(552,000−360,000)÷360,000 = 53.3%で一致
答え： 損益分岐点はA6,000個・B2,000個。DOL≈5.33で、数量10%増は営業利益を約53.3%押し上げる。

直接原価計算の固定費調整 — 全部原価との利益差の正体

直接原価計算は固定製造原価をすべて発生期間の費用(期間原価)として処理し、製品原価には変動製造原価だけを集計します。これにより営業利益が販売量だけで決まり、生産量の増減に左右されないため、経営管理・CVP分析に適します。一方、制度会計(外部報告)では固定製造原価も製品原価に含める全部原価計算しか認められません。両者の利益は在庫に含まれる固定費の扱いだけで差が生じます。

差の本質はこうです。全部原価計算では、期末在庫に配分された固定製造原価が資産(棚卸資産)として次期に繰り延べられ、当期の費用にはなりません。直接原価計算ではその固定費も当期に全額費用化されます。したがって生産量>販売量(在庫増)の期は、全部原価計算のほうが固定費の繰延べ分だけ利益が大きくなります。逆に在庫減の期は小さくなります。

この橋渡しをするのが固定費調整です。公式は『全部原価計算の営業利益 = 直接原価計算の営業利益 ＋(期末在庫に含まれる固定製造原価 − 期首在庫に含まれる固定製造原価)』。在庫の増減に固定費単価を掛けた金額が、そのまま両利益の差になります。試験では『どちらの利益がいくら大きいか』を、在庫が増えたか減ったかで方向を判断し、金額を固定費単価×在庫増減量で押さえるのが定石です。

設例

当期の生産量1,000個・販売量800個(期首在庫なし)。固定製造間接費は600,000円で全量を当期生産に配賦。直接原価計算による営業利益は500,000円であった。全部原価計算の営業利益を固定費調整で求める。

  1. 固定製造原価の製品単価 = 600,000 ÷ 1,000個 = 600円/個
  2. 期末在庫量 = 生産1,000 − 販売800 = 200個(期首在庫は0)
  3. 期末在庫に含まれる固定費 = 600円 × 200個 = 120,000円(この分が全部原価計算では次期繰延べ)
  4. 固定費調整 = 全部利益 − 直接利益 = 期末在庫固定費 − 期首在庫固定費 = 120,000 − 0 = 120,000円
  5. 全部原価計算の営業利益 = 直接原価計算利益500,000 + 120,000 = 620,000円
  6. 検算: 生産量>販売量(在庫増)なので全部原価計算のほうが利益は大きい、という方向と一致(+120,000円)
答え： 全部原価計算の営業利益は620,000円(直接原価計算より120,000円大きい)。

ABCの計算手順 — 少量多品種製品の原価是正

活動基準原価計算(ABC)は、製造間接費を『活動(アクティビティ)』ごとのコストプールに集計し、活動の消費量を表すコストドライバーで製品に配賦する手法です。伝統的原価計算が直接作業時間や機械時間といった操業度基準ひとつで配賦するのに対し、ABCは段取回数・検査回数・発注回数など活動の実態に即した複数の基準を使う点が本質的な違いです。

なぜこれが重要かというと、操業度単一基準では、生産量に比例しない間接費(段取・検査など)まで数量の多い製品に厚く配賦してしまい、少量多品種の製品が実際より安く、大量生産品が高く見える歪みが生じるからです。少量品はロットが小さく段取や検査の回数が相対的に多いため、本来は多くの間接費を負担すべきなのに、操業度基準ではその負担が数量の多い製品へ転嫁されてしまいます。ABCはこの過小・過大評価を是正します。

計算手順は、①間接費を活動別プールに分ける、②各プールにコストドライバーの総量を割り当ててプール別配賦率を出す、③製品ごとのドライバー消費量に配賦率を掛けて集計する、の3段階です。設例で伝統的配賦とABCの差を数値で確認します。

設例

製品X(大量品9,000個)と製品Y(少量品1,000個)。製造間接費2,000,000円。伝統的には機械時間(X・Yとも1個1時間、合計10,000時間)で配賦。ABCでは、段取プール900,000円(ドライバー=段取回数: X10回、Y40回)と機械稼働プール1,100,000円(ドライバー=機械時間: X9,000時間、Y1,000時間)に分ける。両者の製品単位あたり間接費を比較する。

  1. 伝統的配賦: 配賦率 = 2,000,000 ÷ 10,000時間 = 200円/時間。X・Yとも1個1時間なので、単位間接費はともに200円
  2. ABC段取率 = 900,000 ÷ (10+40)回 = 18,000円/回。ABC機械率 = 1,100,000 ÷ (9,000+1,000)時間 = 110円/時間
  3. X間接費 = 18,000×10 + 110×9,000 = 180,000 + 990,000 = 1,170,000円 → 単位あたり 1,170,000÷9,000 = 130円
  4. Y間接費 = 18,000×40 + 110×1,000 = 720,000 + 110,000 = 830,000円 → 単位あたり 830,000÷1,000 = 830円
  5. 検算: 1,170,000+830,000 = 2,000,000で総間接費と一致。少量品Yは200円→830円へ大幅増、大量品Xは200円→130円へ低下し、少量多品種品の過小評価が是正されたことを確認
答え： 伝統的配賦では両製品とも200円だが、ABCではX130円・Y830円。少量品Yの原価が正しく重く配賦される。

事業部業績評価と戦略的原価管理 — ROI・残余利益・振替価格・原価企画・品質原価

分権化した事業部の業績を測る代表的指標がROI(投下資本利益率=事業部利益÷投下資本)と残余利益(RI=事業部利益−投下資本×資本コスト)です。ROIは比率なので規模の異なる事業部を横並びできる長所がある一方、既存ROIより低いが資本コストは上回る有望案件を、事業部長が『平均ROIを下げるから』と却下してしまう不整合(部分最適)を招きます。RIは資本コストを超える利益額を絶対額で測るため、資本コストを上回る案件は必ずRIを増やし、全社最適と事業部長の判断が一致(ゴール・コングルエンス)します。

事業部間で製品を融通するときの内部振替価格は、供給側の『増分原価＋機会原価』を最低ラインとするのが理論的な一般則です。遊休能力があれば機会原価は0なので最低振替価格は変動費まで下がり、社内取引で全社の利益が増えます。フル操業なら外部販売で失う貢献利益が機会原価として上乗せされ、最低振替価格は市価まで上がります。この一般則で、社内取引すべきか外部調達すべきかが機械的に判定できます。

戦略的原価管理では、原価企画(目標原価=目標売価−目標利益を設定し、設計段階でVE等により原価を作り込む前段管理)、品質原価計算(予防・評価・内部失敗・外部失敗の4分類。予防・評価への投資で失敗コストを抑え総額を下げる)、ライフサイクルコスティング(企画から廃棄までの総コストで評価)が要点です。いずれも『発生後の差異分析』でなく『発生前・全期間での作り込み』に軸足を置く点が、標準原価計算との思想的な違いです。

設例

(1)事業部: 利益900,000円・投下資本5,000,000円・資本コスト12%。新規案件は投資1,000,000円で利益150,000円(利回り15%)。ROIとRIの各判断を示す。(2)振替価格: 供給側の変動費300円、外部市価500円。遊休時とフル操業時の最低振替価格。(3)原価企画: 目標売価20,000円、目標利益率25%のときの目標原価。

  1. (1) 現状ROI = 900,000÷5,000,000 = 18%、現状RI = 900,000 − 5,000,000×12% = 300,000円
  2. (1) 新規案件採用後ROI = (900,000+150,000)÷(5,000,000+1,000,000) = 1,050,000÷6,000,000 = 17.5% → 18%より低下しROI基準では却下されがち(部分最適)
  3. (1) 案件のRI = 150,000 − 1,000,000×12% = 30,000円 > 0 → RI基準では採用。全社RIは300,000→330,000へ増加し全社最適と一致
  4. (2) 遊休時: 機会原価0 → 最低振替価格 = 変動費300円。フル操業時: 機会原価 = 市価500−変動費300 = 200 → 最低振替価格 = 300+200 = 500円(市価)
  5. (3) 目標利益 = 20,000×25% = 5,000円 → 目標原価 = 20,000 − 5,000 = 15,000円(見積原価がこれを上回ればVEで差額を作り込む)
答え： (1)ROIは17.5%へ低下し却下されうるがRIは+30,000円で採用が全社最適。(2)最低振替価格は遊休時300円・フル操業時500円。(3)目標原価は15,000円。
