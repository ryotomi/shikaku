生活習慣病 因果チャート

「塩分過多 → 高血圧 → 腎機能低下」のように、日々の生活習慣が危険因子・疾患・合併症を経て重い転帰へつながる因果の連鎖を有向グラフにしました。 循環器・代謝に加え、眼（白内障・緑内障・加齢黄斑変性）・歯・口腔（歯周病・むし歯）・骨/運動器（骨粗しょう症・サルコペニア・フレイル）まで横断的に収録しています。 ノードをクリックすると、その要因の「原因（何から来るか）」「結果（何を招くか）」「予防・対策」「機序」が右パネルに表示されます。段階・系統で絞り込めます。

このチャートの読み方

ノードは左から右へ「生活習慣・環境要因 → 危険因子・中間病態 → 疾患 → 臓器合併症 → 転帰・機能障害」の順に並びます（実際の横位置は因果の深さで自動計算）。 矢印は原因から結果への向きで、太い実線は関与が特に強い経路、細い実線は関与する経路、赤い破線は「悪循環」（結果が原因側を悪化させる）を表します。

  • ノードをクリック：詳細パネルに説明・原因・結果・機序を表示し、関連する経路を強調します。
  • 段階・系統フィルタ：注目したい臓器系（循環器・腎・代謝など）や段階だけに絞れます。
  • スクロール：図が画面より大きい場合は枠内をスクロールして移動できます。右上の「フルスクリーン」で全画面表示にすると見やすくなります。

代表的な因果の連鎖（例）

  • 塩分過多 → 高血圧 → 慢性腎臓病 → 腎不全・透析
  • 過食・運動不足 → 内臓脂肪 → インスリン抵抗性 → 高血糖 → 2型糖尿病 → 糖尿病腎症 → 透析
  • 脂質異常症・喫煙 → 動脈硬化 → 虚血性心疾患 → 心不全 / 突然死
  • 眼：加齢・喫煙・紫外線 → 加齢黄斑変性 → 失明／2型糖尿病 → 糖尿病網膜症 → 失明
  • 歯・口腔：口腔ケア不足・喫煙 → 歯周病 →（悪循環）2型糖尿病／歯の喪失 → 低栄養・誤嚥性肺炎
  • 骨・運動器：加齢・運動不足・栄養不足 → 骨粗しょう症 → 骨折 → フレイル・要介護
